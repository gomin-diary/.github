# 🌿 고민일기 · GOMIN

**오늘의 고민을 한 장의 그림일기로**

AI에게 고민을 털어놓으세요. 그날의 마음을 따뜻한 그림일기로 남깁니다.

## 우리가 만드는 서비스

고민일기는 AI와 나눈 이야기를 글과 그림으로 남기는 웹 서비스입니다. 혼자 쓰기 어려웠던 일기도 대화부터 시작할 수 있습니다.

학업이나 진로 때문에 막막할 때도 있고 인간관계로 마음이 복잡할 때도 있습니다. 이런 고민을 겪는 청소년과 청년들이 편하게 이야기를 꺼낼 수 있는 공간을 만들고 있습니다.

## 우리가 풀고 싶은 문제

고민을 기록하고 싶어도 어디서부터 써야 할지 몰라 멈추곤 합니다. 어렵게 써 둔 글을 다시 읽다가 당시의 감정이 떠올라 마음이 무거워질 수도 있습니다.

고민일기는 글을 쓰기 전에 이야기를 나누는 데서 시작합니다. 대화로 고민을 풀어낸 뒤에는 친근한 캐릭터와 자연 풍경을 담은 그림으로 그날의 마음을 표현합니다. 글만으로 담기 어려운 감정까지 전하고 싶기 때문입니다.

이렇게 남긴 일기는 컬렉션에 모아 둡니다. 지난 고민을 꺼내 볼 때 그때 받은 위로도 함께 떠올릴 수 있도록 글과 그림을 함께 보관합니다.

고민을 털어놓고 마음을 정리하는 시간이 하루를 조금 더 편안하게 마무리하는 데 도움이 되길 바랍니다.

## 고민일기는 이렇게 이어집니다

**털어놓기 → 마음 정리 → 한 장의 그림일기 → 컬렉션**

1. **털어놓기** · AI에게 지금 고민되는 일과 느끼는 감정을 이야기합니다.
2. **마음 정리** · 대화를 마치고 고민을 요약한 글을 확인합니다.
3. **그림일기 만들기** · 나눈 이야기를 그날의 마음이 담긴 그림으로 남깁니다.
4. **컬렉션에 보관하기** · 완성된 고민일기를 저장합니다. 다시 보고 싶을 때 꺼내 볼 수 있습니다.

현재 첫 버전(MVP)을 개발하고 있습니다.
